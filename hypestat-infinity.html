Import a normalized traffic CSV

Use the exact template columns below. Standard GA4 and Search Console exports need mapping first; the Google + Gemini tab provides a prompt. Extra columns—including visitor-ID, email, and IP-address columns—are rejected. Check path values for private details before import.

date,site,scope,basis,provider,referrer,page,destination,country,metric,value
Column rules

date: calendar date YYYY-MM-DD in the source reporting timezone. scope: public_site, gateway, or onion_service. basis: owner_aggregate or third_party_estimate. provider: short source label. referrer and destination: hostname, direct, or unknown. page: a path without query strings, fragments, or personal identifiers. country: two-letter code or unknown. metric: sessions, pageviews, outbound_clicks, requests, search_clicks, impressions, or visitors. value: nonnegative whole number. Preserve source dates and report timezone in a separate evidence note. Maximum 10,000 rows and 2 MiB per import. Exact duplicate rows are ignored.

01 / Data you can actually obtain

How Google can help

Google Analytics 4

For an authorized site, export aggregate acquisition and page reports. Enhanced measurement can collect page views, page referrers, and outbound link clicks when enabled. Coverage depends on collection settings, consent, blockers, and referrer availability.

Google Search Console

Export clicks and impressions leading to your verified property from Google. These measure search performance, rather than all site visits or private browsing.

Gemini as an optional analyst

Give Gemini a redacted aggregate export and ask it to map columns, find discrepancies, and separate facts from hypotheses. Review its output before import. This page does not connect to Gemini or spend API credits.

Operator attribution needs evidence

Record names only when a reliable public source explicitly establishes their role. Gateway hosting, a Dash label, or a script hash does not prove who operates the underlying site.
