Independent radio access project

Infinity Cellular

A real cellular connection starts with a base station and a working Internet uplink. QuantaPhi is the phone interface and control center, not a substitute for the physical network.

Current status: engineering pilot—not live cellular service. A website cannot transmit LTE radio signals, issue a usable SIM, or create upstream Internet bandwidth by itself. The goal is free access for subscribers, with transparently funded radio equipment and backhaul.

In a one-site pilot, subscribers would connect to a local radio instead of paying for individual LTE subscriptions. The radio network operator still needs to fund its uplink. A private CBRS LTE deployment does not automatically provide nationwide coverage, roaming, SMS, emergency calling or regular phone-number service.

Infinity vs. a cellular carrier

The difference: the website supplies user registration, web calling, Bubbles, network management and access policies. Infinity Cellular must additionally supply legally usable radio spectrum, base stations, authentication, routing, power and an upstream Internet connection. These are separate physical services.

Use the existing Infinity Phone switchboard for web calling once the phone has data. Until the private network is verified, retain existing emergency calling and data service.

Technical references: NIST CBRS band · Open5GS LTE core. Deployment requires appropriate regulatory and safety review.
