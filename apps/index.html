How installation works

Open any app below in Chrome, then tap its Install in Chrome button. If Chrome doesn't offer a prompt, use ⋮ → Install app or Add to Home screen. Apps keep the same website origin; a browser install does not grant phone-wide Android permissions.

Bubbles already has a separate Chrome installation page. Its native Android APK is still required for floating overlays and Android app control.
