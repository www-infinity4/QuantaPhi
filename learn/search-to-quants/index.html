How a search becomes a Quant

By QuantaPhi · AI-assisted draft by Codex · Published October 4, 2026

What is a Quant? In QuantaPhi, a Quant is a record created through search. Its research package can include an overview, extracted terms, sources and links to other Quants. Quants and Infinity website tokens have separate balances.

From search to connected data

  1. Ask a question. A new search starts a research record and a separate search event for wallet crediting.
  2. Extract concrete data. The yellow data zone identifies terms. The research record retains source links and the source indexes available for each extracted item.
  3. Follow an extracted link. An ordinary click on a searchable term runs a new search and creates a child Quant. The child keeps its parent and the original trail’s root.
  4. Build context. The child references the earlier Quant. You can return to the parent or follow related searches from the research-trail panel.

A worked trail

Start with “ruthenium.” The data zone may extract “atomic number.” Follow it to create a second Quant. A later “isotope” search creates a third. The third points back to the second, and the second points back to the first. A separate “catalyst” search can branch from the original record.

Why these links help an AI

An AI with authorized access to the linked records can inspect the question, source excerpts, extracted terms and the route between questions. That context can help distinguish a follow-up from an unrelated topic and identify which source supports a statement. It still needs to check the evidence: a relationship between records is not proof that a claim is correct.

What “contains other Quants” means here

The research package stores references to earlier records instead of making extra spendable copies. Following a reference does not merge ownership or count the referenced Quant again. The actual balance stays in the wallet ledger. Earlier records retain their own identity and evidence.

Extraction to public education

The data extraction zone supplies candidate topics and source context. A public lesson then needs source checking, a clear answer, examples, comparisons and honest review information. These first lessons use a small catalog of selected extraction terms and primary sources. Personal searches and wallet records are not automatically published.

Saving and review status

The trail is retained locally and included in authenticated cloud research revisions when the account is connected. Failed cloud writes remain eligible for retry. AI-assisted discovery terms are labeled separately from source-backed extraction entries. Extracted search links carry the parent reference when opened in another tab in the same browser, provided that the saved parent record is available.
