# Oracle Miracle combined studio

One QuantaPhi Image/Video card keeps the current still-image generator and timeline editor. Its Video tab uses a shared engine adapter for Wan, LTX, HunyuanVideo, CogVideoX and FramePack. Automatic selection prefers FramePack for progressive-animation jobs, LTX for audio/video jobs, and Wan for regular scenes; it only selects configured workflows. It submits one render, not five redundant renders. The finished-image button passes Image-mode artwork into an image-capable video workflow. Finished video plays and downloads in the same card.

## Runtime requirements

This repository contains integration code, not downloaded weights. A running GPU machine with ComfyUI, compatible model nodes, model weights, and tested API-exported workflows is required. Downloading/forking Wan's source does not install its weights or start a GPU server. FramePack requires a compatible ComfyUI wrapper/workflow on this host; its original standalone Gradio app does not expose ComfyUI's API. No installed workflows or running GPU host were available during development. No live AI render was verified.

Configure the site Worker with:

- COMFY_URL: HTTPS base URL of the private GPU render host; never taken from browser input.
- COMFY_TOKEN: optional server-side authorization for that host.
- OPEN_VIDEO_SECRET: private signing secret for wallet-owned jobs and media links.
- OPEN_VIDEO_WORKFLOWS: JSON generated by register-workflow.py from your tested workflows.
- VIDEO_RATE_LIMITER: Cloudflare ratelimit binding; one new render per wallet per minute recommended.

Preserve existing Worker service bindings and deploy worker.js, video-api.mjs and open-video.mjs together. The host must support /prompt, /history/{id}, /upload/image and /view. Use an authentication gateway in front of the GPU host. Host outputs must include encoded MP4/WebM under videos, gifs or images; still images alone are not accepted as a completed video. Host workflow settings determine native model resolution and sampling; the separate Imagine quality setting is for Imagine only. Audio is accepted only when the installed workflow is declared audio-capable. Enable no paid ComfyUI API nodes in open-model workflows. There is no automatic paid provider fallback.

## Register each real workflow

1. Install the chosen model's nodes and weights on the GPU host, and successfully generate a video there.
2. Export its workflow in ComfyUI API format.
3. Run `python3 studio/register-workflow.py wan wan-api.json` to inspect node IDs and inputs.
4. Register with bindings for the actual positive text, seed, frame-count, image and size inputs. Example syntax: `--bind prompt=6:text`; node 6 is only a syntax example, not an assumed node in any model. Repeat for ltx, hunyuan, cogvideo and framepack. Use --audio only for a tested audio-generating graph. All engines share the resulting JSON file.
5. Set that JSON as OPEN_VIDEO_WORKFLOWS. Run an end-to-end render from the QuantaPhi card and check the output file and sound before declaring an engine live.

## Validation

Nine executable Node tests pass for engine selection, workflow binding, actual ComfyUI request shape, wallet-bound job polling, signed media streaming, unsupported audio, Imagine adapter behavior and existing timeline regressions. This is mocked network validation. Multi-engine automatic refinement of the same clip, clip concatenation, GPU provisioning, downloading model weights and native FramePack Gradio support are not implemented.
