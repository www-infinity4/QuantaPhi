6502 program workbench

Enter hexadecimal 6502 machine code, two digits per byte. Load to $0800, step one instruction at a time, or run up to 2,000 instructions. In this workbench only, BRK ($00) stops a demonstration program. CPU interrupt behavior remains available in the underlying engine.

Example: LDA #$41; STA $0400; BRK. This writes A to the virtual Apple screen.
