6502 program workbench

Enter hexadecimal 6502 machine code, two digits per byte. Load to $0800, step one instruction at a time, or run up to 2,000 instructions. In this workbench only, BRK ($00) stops a demonstration program. CPU interrupt behavior remains available in the underlying engine.

Example: LDA #$41; STA $0400; BRK. This writes A to the virtual Apple screen.

No custom program loaded.

Apple IIe auxiliary memory and display controls

Switch 40/80-column output, text page and 80STORE using actual virtual soft-switch addresses. This does not include full double-hi-res graphics or language-card RAM.

40-column text, page 1, 80STORE off

Apple IIe language card

Two software-selectable 4 KiB banks at $D000, shared upper 8 KiB, and main/auxiliary bank isolation. Changing to a write mode performs the two required switch reads. No Apple ROM is included.

Bank 2 · ROM read · RAM write protected

Virtual Disk II · slot 6

Load a disk image you are authorized to use. Accepts 35-track .nib files only (232,960 bytes). Motor, two-drive selection and Q6/Q7 nibble reads use simulated $C0E0–$C0EF soft switches. No online fetches or firmware are included.

Optional: supply your own licensed 256-byte Disk II slot bootstrap ROM. Without it, disk-control tests work but a real Apple II disk operating system cannot boot.
