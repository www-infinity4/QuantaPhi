2. Save the token privately in Cloudflare

Open Cloudflare → Workers & Pages → infinity-brain-clock → Settings → Variables and Secrets. Add the X app's Bearer Token as the encrypted secret X_API_BEARER_TOKEN. Verify your account's numeric X ID through the authenticated X API before configuring X_OWNER_USER_ID. Do not use a display name as that ID.

Open Cloudflare Dashboard ↗
