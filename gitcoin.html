GIT Coin

Build code. Push a commit to your personal GitHub repository. Collect a unique, traceable local receipt for each newly added line. Quant AI's separate review will decide which candidates eventually qualify for awards.

Code lineRepo, commit, file, line and hash
Local databasePrivate SQLite receipts
Credit statusPending, not spendable or cash

Collect with Termux

Requires existing git, gh, node and python3. GitHub CLI must already be authenticated. No npm or paid API.

cd ~
git clone --depth 1 --branch feat/gitcoin-termux-sqlite-20261104 https://github.com/www-infinity4/QuantaPhi.git quantaphi-gitcoin
python3 ~/quantaphi-gitcoin/gitcoin/termux-ledger.py scan --worktree ~/my-repo --repo YOUR_GITHUB/my-repo --intent website --builder human
python3 ~/quantaphi-gitcoin/gitcoin/termux-ledger.py balance
Replace the example repository and path with your own pushed GitHub project.

The database is stored at ~/.quantaphi/gitcoin/receipts.sqlite3. A second scan of the same commit will not duplicate line receipts.

Bubbles and GPT developer receipts

Bubbles may create pending GIT claims for eligible code that it genuinely commits for a consenting user, with a signed task receipt and an explicitly approved owner/operator beneficiary. GPT or another agent is attributed separately. No third-party AI provider participates in or accepts GIT automatically.

Bubble Bits and GPT Coin are distinct proposed credits for verified tool iterations, not code lines. They are not generated by a status animation, or by private AI reasoning.

Business marketplace — proposed

Businesses could someday license useful code, purchase approved GIT units, or accept units for eligible services under signed agreements. These transactions require a real buyer, lawful reuse rights and tested wallet transfers. IBM and other technology companies have not been verified as accepting this GIT Coin.
